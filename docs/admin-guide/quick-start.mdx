# IMQA 4단계로 시작하기

1. **관리자 계정** 또는 **관리 권한 계정의 이메일 주소**와 **비밀번호**를 입력 후 [로그인]을 클릭합니다.

![admin guide 01](./img/admin-guide-01.png)

2. **IMQA에서 분석할 새로운 서비스를 등록하고 발급된 서비스 키를 확인합니다.**

![admin guide 02](./img/admin-guide-02.png)

3. **IMQA SDK, WebAgent 삽입 시 발급된** `서비스 키`**를 사용하여 설치합니다.**
4. **설치 후 서비스 목록에서 데이터가 정상적으로 수집되는 것을 확인하실 수 있습니다!**

![admin guide 03](./img/admin-guide-03.png)
