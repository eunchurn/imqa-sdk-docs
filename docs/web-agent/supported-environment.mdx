## WebView 환경에 IMQA Web Agent 지원 사항

### 지원되는 WebView

-   iOS: WKWebView (iOS 13+)
-   Android: WebView (Android 7.0+)
    

### 주요 제한사항

- **JavaScript 제한**
  - eval() 사용 제한
  - window.open() 제한
  - fetch API 제한
- **네트워크 제한**
  - CORS 제한
  - HTTPS 강제
  - 특정 호스트에 대한 접근 제한
- **보안 제한**
  - Content Security Policy(CSP) 제한
  - HTTPS 인증서 검증
  - 웹소켓 연결 제한
- **플랫폼별 특수 제한**
  - iOS WKWebView:
    - eval() 사용 시 보안 경고 발생
    - fetch API의 CORS 문제
    - 쿠키 동기화 문제
  - Android WebView:
    - JavaScript 실행 권한 설정 필요
    - 네트워크 요청 타임아웃
    - 캐시 처리 문제

### 권장 설정

- **JavaScript 설정**
  - JavaScript 실행 권한 활성화
  - eval() 사용 허용
  - window.open() 허용
- **네트워크 설정**
  - CORS 허용
  - HTTPS 인증서 검증 비활성화
  - 타임아웃 설정
- **보안 설정**
  - CSP 설정
  - 쿠키 동기화 설정
  - 캐시 설정


> [!WARNING]
> - WebView의 설정은 앱 개발자에 의해 제한될 수 있습니다
> - 모든 WebView 환경에서 동일한 동작을 보장할 수 없습니다
> - WebView의 버전에 따라 동작이 다를 수 있습니다

## IMQA Web Agent 프레임워크 지원 사항

### 지원되는 프레임워크
- **React**
  - 버전 16.8 이상
  - React Hooks 지원
  - React Context API 지원
  - Next.js 12 이상 지원
- **Vue.js**
  - Vue 2.6+
  - Vue 3.x
  - Vuex 지원
  - Vue Router 지원
- **Angular**
  - Angular 8 이상
  - Zone.js 0.11.4 지원
  - RxJS 지원
- **Vanilla JavaScript**
  - ES6+ 지원
  - 모듈 시스템 지원 (CommonJS, ES Modules)
  - UMD 번들 지원
- **Next.js (9+)**
- **Nuxt.js (2+)**
- **Remix**
- **Svelte (3+)**
- **SvelteKit**

### 지원되지 않는 프레임워크/환경

- jQuery 기반 프레임워크
- React 16.7 이하
- 서버 사이드 렌더링(SSR) 환경
- **구형 프레임워크**
  - Backbone.js
  - Ember.js 3.x 이하
  - Vue.js 1.x
  - AngularJS (1.x)
        

## IMQA Web Agent 를 패키지로 설치하여 사용하기 위한 필수 기술 요구사항

> [!TIP]
> `npm`, `yarn`, `pnpm`, `bun` 등의 패키지 매니저로 `@imqa/web-agent` 를 설치하여 사용할 수 있는 환경에서의 기술 요구사항입니다. CDN 설치 방식에서는 이 항목은 해당되지 않습니다.

### 필수 지원 기능

- **JavaScript 기능**
  - ES6+ 문법 지원
  - `Promise` 지원
  - `async`/`await` 지원
  - Fetch API 지원
- **Web API**
  - WebSocket 지원
  - Performance API 지원
  - MutationObserver 지원
  - IntersectionObserver 지원
        
- **모듈 시스템**
  - CommonJS (`index.js`)
  - ES Modules (`index.mjs`)
  - TypeScript 타입 정의 (`index.d.ts`)

### 권장 사항

- 최신 브라우저 버전 사용
- TypeScript 사용
- 모던 프레임워크 사용 (React, Vue, Angular)
- HTTPS 프로토콜 사용

## 주의사항

- 프레임워크별 호환성:
  - React: Hooks 기반 기능 사용을 위해 16.8 이상 필요
  - Vue.js: Composition API를 위한 2.6 이상 필요
  - Angular: Zone.js 0.11.4와 호환되는 버전 필요
- 브라우저 호환성:
  - 모든 최신 브라우저는 자동으로 지원됩니다
  - 최소 지원 버전 이하의 브라우저는 기능 제한이 있을 수 있습니다
- 모바일 환경:
  - 모바일 웹 브라우저는 지원됩니다
  - 모바일 앱 내장 웹뷰는 지원되지 않습니다
- 보관련:
  - CSP(Content Security Policy) 설정이 필요한 경우, 해당 설정을 확인해주세요
  - `eval` 사용 제한이 있는 환경에서는 일부 기능이 제한될 수 있습니다
- Internet Explorer는 지원되지 않습니다.
- 구형 모바일 브라우저에서는 일부 기능이 제한될 수 있습니다.
- TypeScript를 사용하는 경우 타입 정의 파일(`index.d.ts`)을 활용하시기 바랍니다.
- UMD 번들은 전역 객체 `IMQA`를 통해 접근할 수 있습니다.
